# Himanshu Sekhar Sahoo - Portfolio

Personal portfolio website built with HTML, CSS, and JavaScript. It presents my background, skills, selected projects, experience, and contact links.

**Live site:** [himanshu-portfolio-01.netlify.app](https://himanshu-portfolio-01.netlify.app/)

## Features

- Responsive portfolio layout with About, Skills, Projects, Experience, and Contact sections
- Dark and light themes
- Interactive project filters and page animations
- Downloadable resume at `assets/resume.pdf`
- Links to GitHub, LinkedIn, and X

## Run locally

No build step or package installation is required. Open `index.html` in a browser, or serve the project root with any static file server.

## Project structure

```text
.
├── assets/
│   ├── images/
│   └── resume.pdf
├── css/
│   └── style.css
├── js/
│   └── script.js
└── index.html
```

## Deploy

The site is static and can be deployed from the repository root. For Netlify, connect the GitHub repository, use the `main` branch, leave the build command empty, and set the publish directory to `.`.
